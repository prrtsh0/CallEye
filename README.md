# CallEye

**CallEye is a realtime pressure-call reader.** It listens to a suspicious call
while it is on speaker, transcribes it with Gnani Prisma, scores scam risk with
a hybrid detector, and shows a calm three-level result — green, amber, red. On
red it guides the user to a guardian.

> ⚠️ **Honest disclaimer:** CallEye is a prototype for a student challenge. A
> green result means *"no warning signs so far"*, never *"safe"*. The tool can
> be wrong. It is **not** a substitute for verifying through official channels,
> and it cannot answer, mute, record, or hang up a call.

## The problem

Pressure calls ("digital arrest", KYC/OTP fraud, fake job fees, fake family
emergencies) trap people into acting before they think. CallEye slows the moment
down: it tells the user, in simple words and a colour, whether the call shows
scam signs — so they can hang up and check.

## What CallEye does (and does not)

| Does | Does not |
| --- | --- |
| Listens on speakerphone (after you tap) | Answer / mute / record / hang up |
| Streams transcript live to the browser | Store audio or transcripts |
| Shows green / amber / red verdict | Claim certainty (green ≠ safe) |
| Alerts a guardian on red | Intercept the real phone call |

## How it works

```
 Browser (PWA)                     FastAPI server                    Gnani
 ┌──────────────────┐    /ws/listen    ┌─────────────────────┐   ┌──────────┐
 │ getUserMedia mic  │──▶ binary audio ─▶│ relay (key held    │──▶│ Prisma   │
 │ AudioWorklet 16k  │                 │  here, never here)  │   │ STT      │
 │ live transcript   │◀── JSON events ──│ detector.analyze_   │◀──│ (WS/REST)│
 │ Pressure Meter     │                 │  update()           │   └──────────┘
 │ colour verdict     │                 └─────────────────────┘
 └──────────────────┘
```

**Hybrid detector** (pure Python + optional small ML classifier):

1. **Normalize** — lowercase, collapse whitespace, script equivalences.
2. **Stages** — track authority, fear, isolation, urgency, ask over a sliding
   30s window plus the whole call.
3. **Pressure** — 0–100 weighted urgency/isolation/ask score with exponential
   decay (half-life ~20s) and trend.
4. **Would-never asks** — OTP/PIN/CVV/UPI/password, remote-access apps, safe
   accounts, money to avoid arrest. A would-never ask → **red** (negation cues
   like "mat/nahi/never" are respected).
5. **Emergency claims** — default **amber** with a verify-first flow; red only
   if a money demand is present *and* isolation/urgency *and* the classifier is
   confident.
6. **Decision** — red latches for the call; amber returns to green only after
   20s without new signals.

Phrase lists live in YAML playbooks (`app/detector/playbooks/`) — data, not code.

## Run it (mock mode — no API key, no network)

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt
cp .env.example .env
uvicorn app.main:app --reload
```

Open http://localhost:8000. Everything works in mock mode: the relay replays a
recorded scripted call, so you can see the transcript, pressure meter, and
colours. `GNANI_MODE=mock` is the default.

### Quick checks

```bash
pytest -q
python -m eval.run --split test      # writes eval/report.md
ruff check .
python scripts/smoke.py http://localhost:8000
```

## Going live (Gnani)

1. Fill in `.env` with your Gnani keys/URLs; set `GNANI_MODE=live`.
2. Read `docs/gnani-notes.md` — the exact wire format must be confirmed from the
   Gnani docs before first live use.
3. Rebuild voice clips: `python scripts/generate_voice.py --live`.
4. Deploy (see `docs/DEPLOY.md`).

## Privacy & safety

- Audio is streamed, never written to disk; transcripts live in memory for the
  session and are not logged.
- No analytics, no third-party scripts, no accounts; guardians/contacts/settings
  live in the device's localStorage only.
- The Gnani key never reaches the browser.
- The app clearly says it can be wrong and is not a substitute for checking
  through official channels.
